# Public candidate instructions

- Treat every file in this repository as public material.
- Keep examples synthetic and free of private project names, source, formulas,
  schemas, fixtures, personal data, credentials, or machine-specific paths.
- Preserve the core guarantees: unknown is distinct from zero, evidence is
  isolated by key, bands are policy-defined rather than statistical, committed
  snapshots are immutable, and serialization is deterministic.
- Keep the package free of runtime dependencies unless the owner explicitly
  accepts a proposal to add one.
- Run `npm run check`, `npm audit`, and `git diff --check` after relevant
  changes.
- Never stage, commit, create a remote, push, host, upload, release, or publish
  without explicit owner authorization.
